# Project — Next.js starter

Scaffolded by BigBro from the `website-next` template.

## Setup

```bash
npm install
npm run dev      # dev server on http://localhost:3000
npm run build    # production build
```

## Structure

- `app/layout.js` — root layout + metadata
- `app/page.js` — home page (replace with your app)
- `app/globals.css` — global styles
- Add API routes under `app/api/...`
