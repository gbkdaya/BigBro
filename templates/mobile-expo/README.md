# Project — Expo (React Native) starter

Scaffolded by BigBro from the `mobile-expo` template.

## Setup

```bash
npm install
npx expo start        # scan the QR with the Expo Go app, or press a / i
```

## Structure

- `App.tsx` — root component (replace with your app)
- `app.json` — Expo config (name, slug, bundle id/package)
- Add navigation with `react-navigation`, state with Context or Zustand, etc.
