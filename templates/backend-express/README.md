# Project — Express backend starter

Scaffolded by BigBro from the `backend-express` template.

## Setup

```bash
npm install
npm start          # API on http://localhost:3000
npm run dev        # auto-restart on change
```

## Endpoints

- `GET /health`
- `GET /api/items`, `POST /api/items`, `GET /api/items/:id`, `DELETE /api/items/:id`

The data store is in-memory — swap it for a real DB when you're ready.
