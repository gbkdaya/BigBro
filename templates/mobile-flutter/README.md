# Project — Flutter starter

Scaffolded by BigBro from the `mobile-flutter` template. Platform folders
(android/, ios/, ...) are generated on first run so the template stays light.

## Setup

```bash
flutter create . --org com.yourorg   # generates android/, ios/, etc.
flutter pub get
flutter run
```

## Structure

- `lib/main.dart` — app entry + home screen (replace with your app)
- `pubspec.yaml` — dependencies (add http, provider/riverpod, sqflite, etc. as needed)
